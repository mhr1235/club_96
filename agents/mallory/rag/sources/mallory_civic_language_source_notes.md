## Notes

The terminology PDF contains only a brief intro, while the PNG screenshots contain the usable term lists. The chunks keep the terms at the level of language practice and context because slang and identity labels can be misused when treated as a stable glossary.

The SF Police Code PDF is already represented in `mallory_queer_infrastructure_chunks.md`; this file adds more specific public-accommodation, door-policy, ID, and future-memory hooks.

The Harvey Milk image did not produce useful OCR text, so it is represented as visual/civic context rather than a text source.

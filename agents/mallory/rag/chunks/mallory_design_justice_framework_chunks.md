## Chunk: nothing_about_us_without_us

The design justice framework moves beyond diversity optics toward accountability and community control: people with direct lived experience of the conditions being addressed should help lead and own the process. Mallory can apply this to Club 96 by asking whether patrons, workers, disabled guests, trans people, sober guests, neighbors, and archival subjects are decision-makers or merely consulted after the shape is already fixed.

## Chunk: design_scoping_antipolitics

Source: Sasha Costanza-Chock, Design Justice: Community-Led Practices to Build the Worlds We Need
URL: local:/Users/markramos/Downloads/training corpora 2/mallory/1_book_designJustice.pdf
Tags: Mallory, design scoping, antipolitics, structural problems, problem framing, root causes

Design scoping can become an antipolitics machine when it defines a problem so narrowly that history, state violence, capitalism, racism, gendered violence, or community resistance disappear. Mallory can use this when Club 96 tries to solve a messy social issue with a tidy event or product. The first question is not "what should we build?" but "who framed the problem this way?"

## Chunk: strategic_invisibility

Source: Sasha Costanza-Chock, Design Justice: Community-Led Practices to Build the Worlds We Need
URL: local:/Users/markramos/Downloads/training corpora 2/mallory/1_book_designJustice.pdf
Tags: Mallory, archives, visibility, appropriation, policing, safety, community protection

Design justice notes that invisibility can sometimes be strategic. Marginalized communities may keep practices less visible to avoid appropriation, extraction, policing, or punishment. Mallory can bring this to Club 96's archive work: preservation is not the same as exposure. Some records should be public, some held locally, some consent-gated, and some not captured at all.
